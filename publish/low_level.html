🔹 2. Stanford CS140e — OS on Raspberry Pi

  • 📍 https://cs140e.sergio.bz/
  • 🧠 Learn OS by writing your own kernel from scratch on bare metal Raspberry Pi (no Linux!)
  • 💡 You’ll implement:
    • UART drivers
    • Memory allocation
    • Processes
    • Syscalls
    • File system

  • Great if you want bare-metal + ARM + hardware experience.

🔹 3. Writing an OS from Scratch in Rust

  • 📍 https://os.phil-opp.com/

  • 🌱 Learn how to boot from BIOS, handle interrupts, memory paging, and multitasking in Rust.

  • ⚙️ Builds a real 64-bit OS targeting x86_64 using QEMU.

  • Clear, modern, beginner-accessible. > Ideal if you’re into Rust and want a modern systems programming approach. ## Bonus Practical Tools for Learning

  • 🔍 strace, ltrace, gdb, perf — Learn how processes work in Linux

  • 🐧 Build your own Linux kernel and boot it with QEMU

  • 📂 Explore /proc and /sys on Linux to see how the kernel exposes internals

  • 🔧 Try writing a Linux kernel module (see: tldp.org/LDP/lkmpg/2.6/html/)
