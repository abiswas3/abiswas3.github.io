Problem Statement

Given a set of \(n\)-limbed scalars \(\{a^{(i)}\}_{i=1}^s\) where each limb uses \(w\) bits, and elliptic curve points over finite field \(F_p\), \(\{P_i\}_{i=1}^s\), the goal is to compute \[ P = \sum_{i=1}^{s} a^{(i)} P_i\] as fast as possible on a computer. Throughout this post, we use notation \(r=2^w\) and \(R=r^n\).

The Dumb Way

Calculate each \(a^{(i)}P_i\) using doubling and addition, then add them all together to get the final result. In the worst case, the double and add1 take \(2\lceil \log_2 R -1 \rceil\) additions, and then the final result requires \(n-1\) further addition operations.

Example

r = 26 = 64 and n = 1, say we want to compute 52P. As

52 = 0 ⋅ 20 + 0 ⋅ 21 + 1 ⋅ 22 + 0 ⋅ 23 + 1 ⋅ 24 + 1 ⋅ 25

Bit position (i) Bit value 2i ⋅ P Add to result?
0 0 1 ⋅ P No
1 0 2 ⋅ P No
2 1 4 ⋅ P ✅ Yes
3 0 8 ⋅ P No
4 1 16 ⋅ P ✅ Yes
5 1 32 ⋅ P ✅ Yes

This takes 5 doubling operations to get to 32P. In the process we also calculate 16P and 4P. And finally 3 additions
