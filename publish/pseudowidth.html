Pseudowidth

Razbarov’s PseudoWidth

Last time, we saw an example of how short proofs imply that all clauses are narrow, but then we also showed that any valid resolution refutation needs a wide clause, so the proofs must long. We showed this for the basic \(\text{PHP}_{n-1}^{n}\), though the same argument applies to \(\text{FPHP}_{n-1}^{n}\).

Now we’ll do this again, but we will not use width directly, a but a proxy for width - pseudowidth introduced by (Razborov, 2003). Then we will use this again, when working with sparse graphs, along with a new idea called graph closure.

Some Notation

\(\Delta_{G}\left(i\right) = N_G{j}\), the holes that \(i\) is permitted to fly into.

\(\Delta_{C}\left(i\right) := \{j \in V_H : (i,j) \in E \land x_{ij} \in C\}\) - holes can send pigeon \(i\) to and also satisfy clause \(C\).

\(V_{\text{exp}}(G) := V_P\) when \(G\) is an bipartite graph \(V_P \cup V_H\), and otherwise \(V_{\text{exp}}(G) = G\).

What Is Pseudo Width

Heavy Pigeons

Given an unsatisfiable formula \(F = \text{FPHP}_{n}^{m}\), and integer vectors of length \(m\), \(\vec{d} = (d_1, \dots, d_m), \vec{\delta} = (\delta_1, \dots, \delta_m)\), such that, \(\delta_i < d_i\) for all \(i \in [m]\), the pseudowidth of a clause \(C\), denoted \(w_{\vec{d}, \vec{\delta}}\left(C\right)\)

\[w_{\vec{d}, \vec{\delta}}\left(C\right) = \left|P_{\vec{d}, \vec{\delta}}\left(C\right)\right| := \left|\{ i \in [m]: \Delta_{C}\left(i\right) \geq d_i - \delta_i \}\right|\]

The pigeons in \(P_{\vec{d}, \vec{\delta}}\left(C\right)\) are called heavy pigeons in clause \(C\).
How I think of Pseudowidth: If you think of the role of a resolution proof system as starting with all the axioms, and ensuring pigeons cannot be assigned a hole, then the pseudowidth of a clause really measures how many ``important’’ pigeons are there in the clause. These pigeons are important because there are many ways to satisfy these pigeons, and therefore getting rid of them will make a lot of progress.

Super Heavy Pigeons

We denote the super-heavy pigeons in clause \(C\) with

\[P_{\vec{d}}(C) : = \{ i \in [m]: \Delta_{C}\left(i\right) \geq d_i \}\]

\((w_0, \vec{d})\)-axiom

Finally, any clause that contains exactly \(w_0\) super-heavy pigeons where super-heaviness is parameterised by \(\vec{d}\) is called a \((w_0, \vec{d})\)-axiom.

First Key Technical Tool - The Pigeon Filtering Lemma

The above lemma is a generalisation of filtering lemma that was originally introduced in (Razborov, 2003). In the lemma below, \(m\) and \(n\) in our context will refer to the number of pigeons and holes, and \(L\) will be the size of the resolution refutation, but this is a general combinatorial lemma that has nothind do to with the PHP or expander graphs per se.

Fix \(m, n, L \in \mathbb{N}\). Let \(\alpha \in [m]\) and \(w_0\) be an arbitrary parameter such that \(w_0 \ge \alpha^2 \ge 4\) and \(w_0 \ge \log L\). Given any arbitrary set of integer vectors of length \(m\), \(\vec{r}(1), \ldots, \vec{r}(L)\), there exists a vector \(\vec{r} = (r_1, \ldots, r_m)\) with \(r_k \le t=\lfloor \frac{\log m}{\log \alpha}\rfloor -1\), such that for every \(C \in [L]\) one of the following holds:

  1. \(\left|\{ i\in [m]: r_i(C) \le r_i \}\right| \geq w_0\)

  2. \(\left|\{ i\in [m]: r_i(C) \le r_i + 1 \}\right|\le O\left(\alpha w_0\right)\)

The proof follows from the probabilistic method, and the chernoff bounds. See here for handwritten notes for every step of the proof.

How Do We Use The Pigeon Filtering Lemma

The way (De Rezende et al., 2020) and (Razborov, 2003) use this lemma is to show that short proofs imply short pseudo-width for all clauses in the proof.

Then independently, they will show that valid refutations MUST contain a clause with large pseudowidth, therefore resolution refutations CANNOT be short. The proof is remarkably similar to the proof for showing lower bounds for PHP in the dense graph model.

How I think of the following parameters

  • \(m\) and \(n\) mean the usual.
  • \(w_0\) is an upper bound on the proof size in \(\log\) scale. We need this as we will later show that when proof sizes are smaller than \(\mathsf{exp}\left(w_0\right)\) we get a contradiction.
  • \(\alpha = 2\) in the original result by (Razborov, 2003), but here we will set it to \(o\left(r/\log m\right)\) – and this will in some ways force us to have a very very strong expander.

Theorem

Short Proofs Have Small Pseudowidth (Lemma 4.2)

Let π be a resolution refutation for an unsatisfiable CNF formula F = FPHPnm(G). Let w0 be an arbitrary parameter and α ∈ [m] such that w0 ≥ α2 ≥ 4 and w0 ≥ log |π|, and for each i ∈ [m], define $\delta_i = \Delta_{G}\left(i\right)\lfloor\frac{\log \alpha}{\log m} \rfloor$. There exists a vector d⃗ = (d1, …, dm), and δi < di ≤ ΔG(i), a set 𝒜 ≤ |π| of (w0, d⃗) axioms, and a proof π′ which refutes FPHPnm(G) ∪ 𝒜 wuch that wd⃗, δ⃗(π′) = O(αw0).

For any \(C \in \pi\), for \(i \in [m]\), set \[r_i(C) = \lfloor \frac{\Delta_{G}\left(i\right) - \Delta_{C}\left(i\right)}{\delta_i}\rfloor\]

All the parameters are specified to call pigeon filter lemma which says there exists vector \(\vec{r} = (r_1, \dots, r_m)\) where \(r_i \le \lfloor \frac{\log m}{\log \alpha}\rfloor - 1\). Set

\[d_i = \Delta_{G}\left(i\right) - \lceil r_i \delta_i\rceil + \delta_i\]

Using the above definition, It’s not too hard to see that \(d_i = \text{arg}\min_{x \in \mathbb{N}} \lfloor \frac{\Delta_{G}\left(i\right) - x}{\delta_i}\rfloor \le r_i\).

This implies that for a given clause \(C\), for any \(i \in [m]\)

\[r_i(C) \le r_i \implies \Delta_{C}\left(i\right) \ge d_i\] \[r_i(C) \le r_i + 1 \implies \Delta_{C}\left(i\right) \ge d_i - \delta_i\]

The pigeon filter lemma also gives us that for any \(C \in \pi\), we either have

  1. \(\left|\{ i\in [m]: r_i(C) \le r_i \}\right|\geq w_0 \implies \left|\{ i\in [m]: \Delta_{C}\left(i\right) \ge d_i\}\right| \geq w_0\)

If this is the case, kill super heavy pigeons in \(C\) till there are exactly \(w_0\) super pigeons in the strengthened clause \(C'\), which ensures that \(w_{\vec{d},\vec{\delta}}(C) = w_0\). Add \(C'\) to set \(\mathcal{A}\). By definition \(\left|\mathcal{A}\right| \le \left|\pi\right|\).

  1. \(\left|\{ i\in [m]: r_i(C) \le r_i + 1 \}\right|\le O\left(\alpha w_0\right) \implies \left|\{ i\in [m]: \Delta_{C}\left(i\right) \ge d_i - \delta_i\}\right| \le O\left(\alpha w_0\right)\)

This automatically gives us \(w_{\vec{d},\vec{\delta}}(C) = O\left(\alpha w_0\right)\).

Note in the above proof system we are assuming \(\left|\pi\right| < 2^{w_0}\) for some parameter \(w_0\). Later we will set \(w_0\) such that \(2^{w_0} < \mathsf{exp}\left(\Omega\left(n\right)\right)\), and this will give us a contradiction, which will give us that contradiction. REVISIT THIS

Refutations Must Have A Clause With High Pseudowidth

This is the main technical contribution, where we do countign via linear algebra. Before we formally state the lemma, let’s do some setup work.

Notation of matchings as vectors

Theorem

Valid Resolution Refutations MUST have a clause with high pseudowidth (Lemma 4.3)

Setup (What Is Given To Me): I get

  • A parameter ξ ≤ 1/4
  • A bipartite (r, Δ, c) boundary expander G = (VP ∪ VH, E) where c = (1 − 2ξ)Δ, VP = [m] and VH = [n].
  • A slack vector δ⃗ = (δ1, …, δm) where $_i = 4ΔG(i)ξ.
  • A vector d⃗ = (d1, …, dm) such that δi < di ≤ ΔG(i) for all i ∈ [m].
  • An arbitrary parameter w0
  • An small set1 of arbitrary (w0, d⃗)-axioms, 𝒜 such that |𝒜| ≤ (1 + ξ)w0.

What Do I show:

Every valid proof π that refutes FPHPnm(G) ∪ 𝒜 must have a clause at least one clause C ∈ π, such that $w_{\vec{d}, \vec{\delta}}\left(C\right) \ge \frac{r\xi}{4}$

  1. This smallness just ensures, sticking these axioms along with the refutation does not make the short proof any bigger.↩︎

Before we can fully prove this result, we need some setup to introduce linear algbra notation.

Define the closure of a clause

\[\text{Closure}(C) := \text{Closure}_{r, \nu}\left(P_{\vec{d}, \vec{\delta}}\left(C\right)\right)\]

Note that closure is only defined if \(\left|P_{\vec{d}, \vec{\delta}}\left(C\right)\right| \le r\). If for any \(C \in \pi\), if we have \(\left|P_{\vec{d}, \vec{\delta}}\left(C\right)\right| > r\), then \(\left|\text{Closure}_{r, \nu}\left(P_{\vec{d}, \vec{\delta}}\left(C\right)\right)\right| > \frac{r\xi}{4}\).

To see why: \(\xi \le 1/4\) implies \(r > \frac{r\xi}{4}\) and, \(P_{\vec{d}, \vec{\delta}}\left(C\right) \subseteq \text{Closure}_{r, \nu}\left(P_{\vec{d}, \vec{\delta}}\left(C\right)\right)\). This gives us a our wide clause.

So we can safely assume that for every clause \(C \in \pi\), we have \(\left|P_{\vec{d}, \vec{\delta}}\left(C\right)\right| \le r\).

Fix a field \(\mathbb{F}\) of characteristic 0 and for each pigeon \(i \in V_P\), let \(\Lambda_i\) be a vector space over \(\mathbb{F}\) of dimension \(\Delta_{G}\left(i\right) - d_i + \delta_i/4\). Define

\[ \Lambda := \underset{i \in V_P}{\otimes} \Lambda_i\]

where \(\otimes\) denotes the tensor product. Now for each \(i\), define \(\lambda_i: V_H \rightarrow \Lambda_i\), such that for any \(J \subseteq V_H\) such that

  • If \(\left|J\right| \ge \text{dim}(\Lambda_i)\), then \(\text{span}\{\lambda(j): j \in J\}\) spans all of \(\Lambda_i\).
  • If \(\left|J\right| < \text{dim}(\Lambda_i)\), then \(\text{span}\{\lambda(j): j \in J\}\) spans a subspace of \(\Lambda_i\) and has dimension \(\left|J\right|\).

Now for any partial matching \(\psi: V_P \rightarrow V_H\), we can visualise \(\psi\) with a vector of length \(m\), where \(\psi_i = j \in V_H\) represents the hole pigeon \(i\) is sent to hole \(j\), and \(\psi_i = \bot\), means that \(i \notin \text{domain}(\psi)\). For any partial matching \(\psi\), we define

\[\lambda(\psi) := \underset{i \in \text{domain}(\psi)}{\otimes}\lambda_i(\psi_i) \bigotimes \underset{i \notin \text{domain}(\psi)}{\otimes} \Lambda_i\]

where \(\text{domain}(\psi){\otimes} \Lambda_i\), we mean the vector space formed by taking the tensort product of every basis vectors in \(\Lambda_i\).

Note that when \(\text{domain}(\psi) = V_P\), \(\lambda(\psi) \in \mathbb{F}^{\text{dim}(\Lambda)}\) is a vector of length \(\text{dim}(\Lambda)\) or a 1 dimensional vector space. Whenever, \(\text{domain}(\psi) \subset V_P\), we get a set of basis vectors that span a proper subspace of \(\Lambda\). Finally, if \(\text{domain}(\psi) = \emptyset\) then \(\lambda(\psi) = \Lambda\).

So think of \(\lambda\) this way: feeding \(\psi\) into \(\lambda\) should spit out a set of vectors in \(\mathbb{F}^{\text{dim}(\Lambda)}\). Based on the size of the domain of \(\psi\), these vectors could span a 1-dimensional subspace or the full space.

Finally, let \(\mathcal{M}\) denote the set of all partial matchings \(\psi: V_P \rightarrow V_H\). For any clause \(C\), define

\[Z(C) := \{ \psi \in \mathcal{M} : \text{domain}(\psi) = \text{Closure}(C) \land C(\psi) = \texttt{False}\}\]

Finally, we define

\[\lambda(C) := \text{span}\{\underset{\psi \in Z(C)}{\cup}\lambda(\psi) \}\]

It is clear to see that for \(C=\bot\), we have \(P_{\vec{d}, \vec{\delta}}\left(C\right) = \{\}\), and therefore, \(Z(C) = \{ \psi_0 \}\) where \(\text{domain}(\psi_0) = \emptyset\). Therefore \(\lambda(\bot) = \text{span}\{\lambda{\psi_0}\} = \Lambda\).

KEY IDEA Now here’s the trick. We will show that the PHP axioms and the \((w_0, \vec{d})\) axioms, span a much smaller subspace than \(\Lambda\) under \(\lambda\). This is Lemma 4.9 below. Thus, to go from these axioms to the refutation, we must encounter a resolvent that spans a bigger subsace than its parents. But if the pseudowidth of all close is small i.e smaller than \(\frac{r}{2}\), then every resolvent spans a space entirely contained by the space spanned by its parents, thus we can actually never get to \(\bot\), giving us our contradiction This is formally shown in Lemma 4.10.

More, formally Lemma 4.9 says that there exists \[\frac{C_0 \vee x \quad \overline{x} \vee C_1}{C}\] such that \(\text{span}\{\lambda(C)\} \not\subseteq \text{span}\{\lambda(C_0), \lambda(C_1)\}\) (otherwise, how do we get to \(\bot\)). (Remember, in (Beame and Pitassi, 1996), we did the same thing thing with critical pigeons, now we’re playing the same game with subsapces, which is a generalisation.)

But Lemma 4.10 prevents this from happening if \(\max\{\text{Closure}(C_0), \text{Closure}(C_1), \text{Closure}(C)\} \le \frac{r}{4}\). Thus, for the resolvent to span more space, we need some \(C' \in \{C, C_0, C_1\}\) such that \(\text{Closure}(C') > \frac{r}{4} = \frac{k\Delta}{c - \nu} = \frac{r}{4\xi}\). Solving for \(k = \frac{r\xi}{4}\).

This is the second time we use expansion in the proof. The only other use is in the proof for Lemma 4.10 where we show that the set \(\mathcal{M}_D\) is large enough, to do that we need to lower bound how many holes a light pigeon in \(C\) can go to in \(G\) without satisfying a clause \(C\). Strong expansion implies, many holes. Many holes means many vectors in \(\mathcal{M}_D\) which then allows us to span all of \(\Lambda_D\). See proof for more details.

Now as, \(G\) is a \((r,\Delta, c)\) boundary expander, by Lemma 3.3 (contrapositve), we have that if \(\text{Closure}(C') = \text{Closure}_{r, \nu}\left(P_{\vec{d}, \vec{\delta}}\left(C'\right)\right) > \frac{k\Delta}{c - \nu}\) then \(\left|P_{\vec{d}, \vec{\delta}}\left(C'\right)\right| > k \frac{r\xi}{4}\).

This completes the proof.
