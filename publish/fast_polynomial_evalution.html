In the Jolt codebase there is an algorithm that takes as input all evaluations of \(f\) over \(\{0, 1\}^n\) and an \(r \in \mathbb{F}^n\) and outputs \(\tilde{f}(r)\) where \(\tilde{f}\) is the multilinear extension of f. The algorithm that’s implemented is suboptimal. Implementation

More specifically, the current algorithm does the following: 1. Given \(\vec{r} \in \mathbb{F}^n\) it computes all \(N = 2^n\) evaluations of Lagrange basis polynomials \(\Big\{\chi_{\vec{w}}(\vec{r})\Big\}_{\vec{w} \in \{0,1 \}^n}\) where \(\chi_{\vec{w}}(\vec{r}) = \prod_{k=0}^{n-1} (1 -r_k)(1-w_k) + r_kw_k\). Using the cite techniques descriped in, these can be done in time \(2^n\).

  1. Then to compute the answer we compute a dot product, which is a further \(2^n\) operations. \[\widetilde{f}(\vec{r}) = \sum_{w \in \{0,1\}^n}f(w)\chi_{\vec{w}}(\vec{r})\]

In what follows, we describe how to speed up the implementation by a factor of 2.
