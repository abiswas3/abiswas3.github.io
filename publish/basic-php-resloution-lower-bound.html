Resolution PHP Lower Bound

PHP Refutations In Resolution

This post is about Refuting The Basic Pigeon Hole Principle In The Resolution Proof System. Here the number of pigeons will be \(n\) and the number of holes will be \(n-1\), and we only consider fomulae that fail to satisfy the Pigeon and Hole Axioms (so we are not considering the functional and onto axioms). See for a refresher on the resolution proof system, and the axioms of the PHP principle.

The main result we wish to prove is that all refutations have large size. The original result is by (Haken, 1984) but we go over the proof by (Beame and Pitassi, 1996) which is a simplification of the original proof.

Theorem

Proof Size Lower Bound For PHPn − 1n

Any refutation of π for PHPn − 1n in the resolution proof system has size Ω(expn).

Preliminary Material

Sometimes it is easier to deal with formulae with no negated variables. For PHP refutations, as is standard in the literature (see (Razborov, 2003), (Beame and Pitassi, 1996)) we will often do the following converstion to obtain clause \(C^+\) from a clause \(C\).

Definition

Positive Conversion

Let π denote a refutation for PHPnm. For any clause C ∈ π, we denote with C+ the clause obtained by replacing every negated variable $\overline{x_{ij}} \in C$ with the subclause $X_{ij} = \underset{i'\neq i}{\lor} x_{i'j}$

Finally we will call an assigment \({\alpha^*_{}}\) which maps pigeons to holes, critical, if it matches every hole with a unique pigeon, and every pigeon but one to a unique hole.

Definition

Critical Assignments

An assignment αi* ∈ {0, 1}n × (n − 1) is i-critical if every pigeon except i gets assigned a unique pigeonhole and every hole gets assigned a unique pigeon k ≠ i.

One reason we work we work with critical assignments, is that they have the same behaviour both the converted clause and the original clause.

Let \(\pi\) be a \(\text{PHP}_{n-1}^{n}\) refuation in the resolution proof system. For any clause \(C \in \pi\), let \(C^+\) denote its positive version. Then for any critical assignment \({\alpha^*_{}} \in \{ 0, 1\}^{n\times n-1}\), we have \(C({\alpha^*_{}}) = C^+({\alpha^*_{}})\).

The first thing to note is that any critical assignment satisfied all hole axioms. Say \({\alpha^*_{}}\) sets \(x_{ij} = 1\) for arbitrary literal in clause \(C\). Then hole \(j\) is already matched to pigeon \(i\). Therefore, hole \(j\) cannot be filled by any other pigeon other than \(i\) (by hole axioms being satisfied). Therefore, \(X_{ij} = \underset{i'\neq i}{\lor} x_{i'j} = 0 = \overline{x_{ij}}\).

Now, say \({\alpha^*_{}}\) sets \(x_{ij} = 0\) for arbitrary literal in clause \(C\). \(i\) is not matched to hole \(j\), but since \({\alpha^*_{}}\) is \(k\)-critical for some \(k\), all the holes are matched to unique pigeons. Therefore hole \(j\) gets a pigeon \(i'\) that is not \(i\) nor \(k\). Therefore \(X_{ij} = 1\) as \(x_{i'j} = 1\).

Small Sized Proofs Must Have Small Width

Before going into the details of the proof, we describe the general proof strategy:

  • Show that for all valid refutations, a small proof size implies that every clause in the proof has small width – this is described the Restriction Step below

  • However, any show that a valid PHP refutation MUST have large width.

  • Thus, we can conclude that the size of of the proof must be large.

This theme will continue when showing stronger lower bounds for the more constrained PHPs. Instead of width, we will use pseudowidth, which can be seen as the number of interesting literals in a clause. See for details.

Finally, the width of a clause, denoted with \(w(C)\) is the number of literals in the clause.

Theorem

Resolution Refuations Have Large Width

Every refutation π of PHPn − 1n must contain a clause C̃ ∈ π with $w(\widetilde{C}^{+}) \geq \frac{n^2}{9}$

For any clause \(C\) let \[P(C) = \{ i \in [n]: \exists {\alpha^*_{i}} \in \{ 0, 1\}^{n\times (n-1)} \text{ s.t } C({\alpha^*_{i}}) = 0\}\]

In simple words, let \(A = \{{\alpha^*_{1}}, \dots, {\alpha^*_{k}}\}\) be all the critical assignments, and \(A' \subseteq A\) the critical assignments such that \(C({\alpha^*_{j}}) = 0\) for all \({\alpha^*_{j}} \in A'\). Then \(P(C)\) is the set of pigeons associated with \(A'\).

Let \(\mu(C) = \left|P(C)\right|\). Then for each pigeon axiom \(P_i\), by definition \(\mu(P_i) = 1\)

As any critical assigmnent that does not include \(i\) will satisfy \(i\), therefore it will satisfy \(P_i\). Thus, the only critical assignments for which \(P_i\) is not satisfied, are the ones that screw over pigeon \(i\).

On the other hand, \(\mu(\emptyset) = [n]\) (as all assignments, and therefore all critical assignment falsify \(\emptyset\) by definition).

Thus from going from \(P_i\)’s to \(\emptyset\), there must be some clause in the proof, lets call it \(\widetilde{C}\), where for \(\epsilon=1/3\)

For any application of resolution where we get \(C\) from \(A\) and \(B\), if a critical assignment \(\beta \in \{ 0, 1\}^{n \times (n-1)}\) such that \(C(\beta) = 0\), then it must be that one of \(A(\beta) = 0\) or \(B(\beta) = 0\) (that is the definition of a resolvent). Therefore, we get \(\mu(C) \le \mu(A) + \mu(B)\).

Now to get to \(\mu(\emptyset) = n\) from \(\mu(P_i)\), we have some clause \(\widetilde{C}\) that is a resolvent of clauses \(A\) and \(B\) with \(\mu(A), \mu(B) \ge \epsilon n\).

Note: Here setting \(\epsilon=1/3\) is arbitrary, we could have used any arbitrary constant.

\[\epsilon n \le \mu(\widetilde{C}) \le 2\epsilon n\]

Pick arbitrary \(i \in P(\widetilde{C})\) and arbitrary \(j \notin P(\widetilde{C})\). Let \({\alpha^*_{i}}\) denote the critical assignment which causes \(i\) to be in \(P(\widetilde{C})\). We construct \({\alpha^*_{j}}\) by swapping row \(i\) and \(j\) in \({\alpha^*_{i}} \in \{ 0, 1\}^{n \times (n-1)}\).

Now, as \(\widetilde{C}({\alpha^*_{i}}) = 0\), and \({\alpha^*_{i}}\) is critical, by the lemma above we have \(\widetilde{C}^{+}({\alpha^*_{i}}) = 0\).

We also have \(\widetilde{C}({\alpha^*_{j}}) = 1\)

Assume not, then this implies \(j \in P(\widetilde{C})\) as \({\alpha^*_{j}}\) is critical, which contradicts our assumption.

Now \(\widetilde{C}^{+}({\alpha^*_{i}}) = 0\) and \(\widetilde{C}^{+}({\alpha^*_{j}}) = 1\), and as we swapped exactly ONE row to construct \({\alpha^*_{j}}\), there is exactly ONE literal, lets call it \(x_{ik} \in C^+\), for some \(k \in [n-1]\), that is set to true by \({\alpha^*_{j}}\), and was false in \({\alpha^*_{i}}\). Now \(i\) and \(j\) were arbitrary. So for each such pair, I will have a unique \(x_{ik}\). If we have \(s = \mu{\widetilde{C}} = \left|P(\widetilde{C})\right|\), and \(n-s\) such \(j \notin P(\widetilde{C})\), then the total number of literals in clause \(\widetilde{C}\) is \(s(n-s)\). Now we have \(s \ge \epsilon n\) and \(n-s \ge (n-2\epsilon n) = n(1-2\epsilon)\).

Small Sized Proofs Imply Small Width Proofs

Wide Clause: Given \(\epsilon \in (0,1)\) and a refutation \(\pi\) for \(\text{PHP}_{n-1}^{n}\), we say a clause \(C \in \pi\) is \(\epsilon\)-wide if \(w(C^+) \ge \epsilon n^2\)

Let \(\pi\) be a refutation of \(\text{PHP}_{n-1}^{n}\), and \(\pi^{+} = \{C^+\}_{C\in \pi}\) be the refutation obatined by replacing negated literals in every clause in \(C \in \pi\). Let \(S_0\) be the number of \(\epsilon\) wide clauses in \(\pi^+\) (from the above lemma we know that \(S_0 \ge 1\) for \(\epsilon \le 1/9\)). Note \(S \le \left|\pi\right|\). Each of these clauses have at least \(\epsilon\) fraction of the \(n^2\) possible literals. Therefore by the averaging argument, there must be one literal, lets call it \(x_{ij}\), that is present in at least \(\epsilon S_0\) of all these wide clauses. We set \(x_{ij} = 1\) and \(x_{i'j} = 0\) for all \(i' \neq i\), and set \(x_{ij'} = 0\) for all \(j' \neq j\). Setting \(x_{ij} = 1\) implies we satisfy at least \(\epsilon S_0\) wide clauses. Thus, the number of wide clauses left is at most \(S_0(1 - \epsilon)\). Furthermore, once we apply this restriction to \(\pi\) (and therefore \(\pi^+\)) we are left with a restriction of \(\pi\), lets call it \(\pi_1\), which is a resolution refutation of \(\text{PHP}_{n-2}^{n-1}\).

Now we repeat the same process \(k=\lceil\frac{\log S_0}{\epsilon}\rceil\) times such that we end up with restricted proof \(\pi_k\) which is a refutation of \(\text{PHP}_{n-k -1}^{n-k}\). After \(k\) restrictions, there should be no wide clauses left in \(\pi\). To see why

\[\begin{align*} \text{Number of wide clauses left} &\le (1 - \epsilon)^k S_0 \le e^{-k\epsilon}S_0 < 1 \end{align*}\]

Where the last inequality comes from plugging in the value of \(k\), and the second last inequality comes from Taylors theorem. However, from the lemma above we have that \(\exists \widetilde{C}\in \pi_k\) such that \(w(\widetilde{C}^+) \ge (n-k)^2/9\), if \(\pi_k\) is a valid refutation of \(\text{PHP}_{n-k-1}^{n-k}\) (which we assumed to be the case as \(\pi\) was a valid refutation, and \(\pi_k\) is just a restriction of \(\pi\)).

Combining the two we get, that

\[ \frac{(n-k)^2}{9} = \frac{\left(n-\frac{\log S_0}{\epsilon}\right)^2}{9} \le w(\widetilde{C}^+) < \epsilon n^2\]

As \(\epsilon\) is some small constant, and solving for \(S_0\) we get \(S_0 \ge \mathsf{exp}{\Omega\left(n\right)}\). And as \(S_0 \le \left|\pi\right|\), we get a lower bound on the size of any refutation.
