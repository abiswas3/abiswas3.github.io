Faster Polynomial Evaluaton

Acknowledgements

Justin Thaler recommended I look into the current implementation, and sketched out the idea to speed up polynomial evaluation. All the algorithmic innovation is his, and all potential technical bugs in the implementation are mine.

Problem Statement

Fix \(n \in \mathbb{N}\) and define \(N = 2^n\). In the Jolt codebase there is an algorithm that takes as input a vector \(f \in \mathbb{F}^N\) and an \(\vec{z} \in \mathbb{F}^n\) and outputs \(\widetilde{f}(\vec{z})\) where \(\widetilde{f}\) is the multilinear extension (MLE) of \(f\). See Chapter 3 of (Thaler, 2020) for details on how to compute MLE of a vector.

More specifically, the current algorithm does the following:

  1. Given \(\vec{z} \in \mathbb{F}^n\) it computes all \(N = 2^n\) evaluations of Lagrange basis polynomials \(\Big\{\chi_{\vec{w}}(\vec{z})\Big\}_{\vec{w} \in \{0,1 \}^n}\) where \(\chi_{\vec{w}}(\vec{z}) = \prod_{k=1}^{n} (1 -z_k)(1-w_k) + z_k w_k = eq(\vec{w}, \vec{z})\). Using the memoisation algorithm described in (Vu et al., 2013), this computation require \(2^n\) multiplications. See Lemma 3.8 of (Thaler, 2020) for a simple exposition and analysis of this algorithm. An implementation can be found here.

  2. Then to compute the answer we compute a dot product, which requires \(2^n\) multiplications. \[\widetilde{f}(\vec{z}) = \sum_{w \in \{0,1\}^n}f(w)\chi_{\vec{w}}(\vec{z})\]

In what follows, we describe how to speed up the implementation by a factor of 2.

A Constant Factor Improvement

Re-writing the definition of MLE of \(f\) we get \[ \begin{align} \widetilde{f}(\vec{z}) &= \sum_{\vec{w} \in \{0,1\}^n}f(w)\cdot \chi_{\vec{w}}(\vec{z})\\[10pt] &=\sum_{\vec{w} \in \{0,1\}^n} f(\vec{w})\cdot eq(\vec{z},\vec{w}) \\[10pt] &= \sum_{w_1 \in \{0,1\} } eq(z_1,w_1) \sum_{w_2 \in \{0,1\} } eq(z_2,w_2) \ldots \sum_{w_n \in \{0, 1\}} eq(z_n,w_n) * f(w_1,...,w_n) \end{align} \]

Notice that \[ \begin{align} \sum_{w_n \in \{ 0, 1\}} \operatorname{eq}(z_n, w_n) \cdot f(w_1, \ldots, w_n) &= f(w_1, \ldots, w_{n-1}, 0) \notag \\ &\quad + z_n \cdot \left( f(w_1, \ldots, w_{n-1}, 1) - f(w_1, \ldots, w_{n-1}, 0) \right) \end{align} \]

which is one multiplication for every instantiation of \((w_1, \ldots, w_{n-1})\), therefore it is a total of \(2^{n-1}\) multiplications.

Now if we compute things inside out i.e \(j \in \{n, \ldots, 1\}\),

  • The first iteration of the loop is \(2^{n-1}\) multiplications
  • The second iteration will be \(2^{n-2}\) multiplications
  • …
  • The \(j\)’th itertion will be \(2^{n-j}\) multiplications
  • …
  • The last iteration is just 1 multiplication.

Thus, there is a total of \(2^n\) multiplications, instead of the two step process described above, each of which had \(2^n\) multiplications.

Note About Script

The following plotting code was generated by chat GPT

import json
import os
import matplotlib.pyplot as plt

# Path to criterion benchmark output
base_path = "target/criterion/evals"

# Containers for results
results = {
    "dot-product": {"x": [], "y": [], "err": []},
    "inside-out": {"x": [], "y": [], "err": []},
}

# Iterate over all benchmark subdirectories
for entry in os.listdir(base_path):
    subdir = os.path.join(base_path, entry)
    if not os.path.isdir(subdir):
        continue

    if entry.startswith("dot-product-") or entry.startswith("inside-out-"):
        algo, param = entry.rsplit("-", 1)
        try:
            param = int(param)
        except ValueError:
            continue

        path = os.path.join(subdir, "new", "estimates.json")
        if os.path.exists(path):
            with open(path) as f:
                data = json.load(f)
                mean = data["mean"]["point_estimate"] / 1e6  # ns → ms
                stderr = data["mean"]["standard_error"] / 1e6

                results[algo]["x"].append(param)
                results[algo]["y"].append(mean)
                results[algo]["err"].append(stderr)

# Plotting
plt.figure(figsize=(10, 6))

for algo, data in results.items():
    if data["x"]:
        # Sort by param size
        sorted_data = sorted(zip(data["x"], data["y"], data["err"]))
        x, y, err = zip(*sorted_data)
        plt.errorbar(
            x, y, yerr=err, label=algo, marker="o", capsize=4,
            linestyle="-", linewidth=2
        )

plt.yscale("log")
plt.xlabel("Param size (log2)")
plt.ylabel("Time (ms, log scale)")
plt.title("Criterion Benchmark: dot-product vs inside-out")
plt.legend()
plt.grid(True, which="both", linestyle="--", linewidth=0.5)
plt.tight_layout()
plt.show()
