Problem Set 1

  1. Counting sort. Let $A=(a_1,\ldots,a_n)$ be a list of $n\geq 1$ integers, where $0\leq a_i<n$ for every $i$. Counting sort initializes an array $C[0\ldots n-1]$ to zero, increments $C[a_i]$ for each input element, and then outputs each integer $x=0,1,\ldots,n-1$ exactly $C[x]$ times. Prove that the output contains exactly the input elements (including repeated values), is sorted in nondecreasing order, and is produced in $O(n)$ time in the word-RAM model. Assume every integer from $0$ to $n$ fits in one machine word, and that word operations and array accesses take constant time.

  2. Harmonic series. For $n\geq 2$, let $H_n=\sum_{i=1}^{n}\frac{1}{i}$. Prove that $H_n=\Theta(\log_2 n)$.

  3. Palindromes on one tape. A binary string $x\in\{0,1\}^n$ is a palindrome if $x$ equals its reversal. The input occupies consecutive cells of a single read/write Turing-machine tape, with blanks on either side; the head starts on the leftmost input symbol (or on a blank if $n=0$). The machine may use additional tape symbols. Write down a deterministic one-tape Turing machine that accepts exactly the palindromes. Specify its tape alphabet and transition rules, either as a table or as an unambiguous state-by-state description. Prove that it is correct and that it halts after $O(n^2)$ transitions on every input of length $n$.

  4. Asymptotic behavior of functions. For each collection below, arrange the five functions in increasing order of asymptotic growth as $n\to\infty$: whenever $f_a$ precedes $f_b$, require $f_a=O(f_b)$. Group functions with the same $\Theta$ growth rate inside curly braces, and briefly justify your ordering.

    For example, if $f_1=n$, $f_2=\sqrt{n}$, and $f_3=n+\sqrt{n}$, the ordering is $(f_2,\{f_1,f_3\})$; the functions inside the braces may appear in either order.

    All logarithms below are base $2$. In part (b), let $n$ tend to infinity through even integers.

    Function(a)(b)
    $f_1$$(\log_2 n)^{2019}$$2^n$
    $f_2$$n^2\log_2(n^{2019})$$n^3$
    $f_3$$n^3$$\binom{n}{n/2}$
    $f_4$$(2.019)^n$$n!$
    $f_5$$n\log_2 n$$\binom{n}{3}$

  5. Dynamic-array append. A dynamic array starts empty with capacity $1$. An append writes the new element in the next free slot when the array is not full. When it is full with capacity $c$, it allocates a new array of capacity $2c$, copies the $c$ stored elements, and then writes the new element. Assume reading or writing one element costs $O(1)$ time, and allocating and initializing an array of capacity $c$ costs $O(c)$ time. Prove that any sequence of $m\geq 1$ appends starting from an empty array takes $O(m)$ total time. Conclude that the amortized time per append is $O(1)$.

  6. Merge sort. Merge sort sorts an array of $n\geq 1$ elements by recursively sorting two halves of sizes $\lfloor n/2\rfloor$ and $\lceil n/2\rceil$, then merging the sorted halves. An array of length $1$ is handled in $O(1)$ time, and splitting and merging together take $O(n)$ time for an array of length $n$. Prove that the worst-case running time of merge sort is $O(n\log_2 n)$.
