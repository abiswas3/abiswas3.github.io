Time and Space

So far we’ve only been talking about computability theory, and refreshing relevant material in computability theory. We did that to introduce the general model of computation we will be working with in this class– the multi-tape TM, and also to provide a brief refresher to concepts like diagonalisation, reductions and completeness, which will be useful later on. In this lecture we define time and space complexity. In computational complexity we are interested in the most efficient way to solve a given problem, or in other words, how do you solve with it with the fewest resources possible. In this lecture we will formalise and study time and space as resources.

Definition

Let $M$ be a deterministic TM and let $x \in \Sigma^*$. The running time of $M$ on $x$, denoted by $\mathrm{time}_M(x) \in \mathbb{N} \cup \lbrace \infty\rbrace $, is the number of steps $M$ takes on input $x$ before halting, or $\infty$ if $M$ does not halt on $x$.

Definition

Let $M$ be a deterministic TM with a read-only input tape and let $x \in \Sigma^*$. The space used by $M$ on $x$, denoted by $\mathrm{space}_M(x) \in \mathbb{N} \cup \lbrace \infty\rbrace $, is the total number of distinct work-tape cells that $M$ scans when run on input $x$.

Remark

Note that $\mathrm{space}_M(x)$ can be finite even if $M$ does not halt on $x$.

Remark

We make the input tape read-only so that the cells holding the input do not count towards space. Otherwise every machine would use at least $n$ cells on inputs of length $n$, and sub linear space bounds such as $\log n$ would be meaningless.

Definition — Time Complexity of a TM

Let $M$ be a deterministic TM. The time complexity of $M$ is the function $T_M : \mathbb{N} \to \mathbb{N} \cup \lbrace \infty\rbrace $ given by $T_M(n) = \max \lbrace \mathrm{time}_M(x) : x \in \Sigma^n \rbrace $.

Definition — Space Complexity of a TM

Let $M$ be a deterministic TM with a read-only input tape. The space complexity of $M$ is the function $S_M : \mathbb{N} \to \mathbb{N} \cup \lbrace \infty\rbrace $ given by $S_M(n) = \max \lbrace \mathrm{space}_M(x) : x \in \Sigma^n \rbrace $.

The maxima exist because $\Sigma^n$ is finite and $\mathbb{N} \cup \lbrace \infty\rbrace $ is totally ordered. We also define complexity classes, which are sets of languages that can be decided within a given amount of time or space.

Definition — Time Complexity Classes

Let $L \subseteq \Sigma^*$ and $T : \mathbb{N} \to \mathbb{N}$. We say $L \in \mathsf{DTIME}(T)$ if there exists a deterministic TM $M$ that decides $L$ with $T_M \in O(T)$.

Definition — Space Complexity Classes

Let $L \subseteq \Sigma^*$ and $S : \mathbb{N} \to \mathbb{N}$. We say $L \in \mathsf{DSPACE}(S)$ if there exists a deterministic TM $M$ with a read-only input tape that decides $L$ with $S_M \in O(S)$.

The above definitions capture the worst case performance of a machine as a function of the size of the input. Alternatively, one can also consider the average case performance/complexity. We are typically interested only in asymptotics. One reason for such a decision is that the runtimes obtained through analysis are obtained by using a multi-tape TM as a model of computation. If we used another model, we might need a different set of constants. Another reason for only being interested in the asymptotics is the speedup theorem, which we will prove later in the lecture.

Observation

Any language $L$ for which membership depends on reading the entire input requires time at least $n$.

Example

Parity $\in \mathsf{DTIME}(n)$: Read the input from left to right keeping track of the parity of bits so far in the machine’s state.

Note that the above example generalises to membership of any regular language in linear time.

Example

Palindromes $\in \mathsf{DTIME}(n)$: Copy the input onto another tape in reverse order. Then check cell by cell up to the middle.

Example

Define $L = \lbrace x\#x : x \in \lbrace 0,1\rbrace ^*\rbrace $, then $L \in \mathsf{DTIME}(n)$: Read the input from left to right until a $\#$ is encountered. Copy the part of the input after that onto a separate tape. Now move the tape heads back to the left end, and compare the part of the input until the $\#$ bit by bit with the string written on the work tape, accepting if and only if they are identical.

We still don’t actually have explicit examples of languages that are not in $\mathsf{DTIME}(n)$ (except those that follow from application of the time hierarchy theorem).

Other interesting classes include

  1. $\mathsf{P} = \cup_{k} \mathsf{DTIME}(n^k)$

  2. $\mathsf{E} = \cup_{k} \mathsf{DTIME}(2^{nk})$

  3. $\mathsf{EXP} = \cup_{k} \mathsf{DTIME}(2^{n^k})$

In all of the above examples, $n$ represents the size of the input. Although linear time is a very useful complexity class, it’s not robust to the choice of how we choose to model computation. For example, a language that’s linear in the multi-tape TM model, may not be linear another model (like single tape TM, or RAM). This is where the class $\mathsf{P}$ is very useful. Although not formally provable, a wildly held belief is that regardless of which model we use, if a language is in $\mathsf{P}$ in one computational model, then it is in $\mathsf{P}$ is all other “reasonable” and deterministic computational models. The reason we cannot formally prove this statement is because it’s hard to define what a “reasonable” model of computation is.

Remark

The deterministic quantifier is quite important as the above conjecture is not believed to hold for quantum TMs. The Factoring problem is believed to be hard for classical TMs but is solvable in polynomial time on quantum TMs.

Some interesting examples of languages in $\mathsf{P}$:

  1. Fundamental optimisation problems like Linear Programming are in $\mathsf{P}$. So is Max-Flow.

  2. Checking if a number is prime or not is in $\mathsf{P}$.

  3. 2-SAT, GCD of 2 integers is also in $\mathsf{P}$.

Theorem — Time Speedup Theorem

Let $T :\mathbb{N} \rightarrow \mathbb{N}$ be a time function and let $r \in \mathbb{N}$ be a positive integer. Suppose a TM $M$ decides a language $L \subseteq \Sigma^*$ with time complexity $T(n)$, where $n$ is the length of the input. Then there is another TM $M^{\prime}$ that decides $L$ with time complexity $\frac{T(n)}{r} + O(n)$.

Proof

The idea is to let $M^{\prime}$ treat a block of $m$ consecutive symbols of $M$ as a single symbol, so that one step of $M^{\prime}$ does the work of about $m$ steps of $M$. This is allowed because a TM can have any finite tape alphabet. Figure 1 shows the blocking. The block size is $m = 6r$, where $r$ is the speedup factor in the theorem.

Phase 1: compress the input. $M^{\prime}$ reads $M$’s input $x$, of length $n$, and copies it onto the its work tape with $m$ symbols of $x$ in each cell. That is each cell has of this tape has $n/m$ input alphabets (assume things are divisible otherwise pad). This copying needs time $O(n)$ to read $M$’s input tape. Once this copying is done, $M$’s chunked input tape will be the input tape. The other tapes of $M$ start blank and each cell holds $m$ symbols from $\Gamma$. See Figure 1.

Phase 2: simulate $m$ steps of $M$ using 6 steps of $M^{\prime}$. A round is a sequence of 6 consecutive steps of $M^{\prime}$ that simulates the next $m$ steps of $M$. So $M^{\prime}$ does 1 round for every $m$ steps that $M$ does. A step of a TM depends on the current state and on the cells under the heads: together they determine the new state, the symbols written and the head moves.

$m$ steps of $M$ means the following. On each work tape, $M$ writes at most $m$ cells. On each tape, $M$ reads at most $m+1$ cells. $M$ goes through $m$ state transitions $q_0 \to q_1 \to \cdots \to q_m$.

To simulate this, $M^{\prime}$ does not need to model the intermediate steps. It needs $q_0$, the contents of the cells that $M$ can read and the positions of its heads at the start, and it needs $q_m$, the final contents and the final head positions. If $M^{\prime}$ can produce these, it has done $m$ steps of $M$.

Consider the next $m$ steps of $M$. Fix any work tape of $M$. A round of $M^{\prime}$ goes as follows. It starts with $q_0$ in its state. If $M$ starts on cell $i$, then this cell belongs to some block $B_j$ of $M^{\prime}$. In $m$ steps $M$ moves at most $m$ cells, so it can only reach cells in the blocks $B_{j-1}$, $B_j$ and $B_{j+1}$ (Figure 2). These are all the blocks that $M$ could read or write in these $m$ steps, which is why $M^{\prime}$ reads exactly these three blocks. $M^{\prime}$ cannot tell in advance which neighbour $M$ will use, because that depends on the state of $M$ and on the contents of the cells, and with several tapes on what the other heads read. So it scans these blocks by going left, right, right and left (Figure 2). This takes 4 time steps. Now $M^{\prime}$ has read everything $M$ could read. We define $\delta^{\prime}$ so that, from $q_0$ and what $M^{\prime}$ has read, it gives $q_m$, the final contents and the final head positions. It writes back the blocks that changed. At most 2 blocks were written to by $M$ since the cells $M$ visits are at most $m+1$ consecutive cells. So $M^{\prime}$ writes two blocks which takes 2 steps. The last of these steps also moves the head of $M^{\prime}$ onto the block that holds the head of $M$, and the state of $M^{\prime}$ now holds $q_m$, ready for the next round. The heads on all the tapes do this at the same time, so a round takes 6 steps in total.

Counting steps. $M$ runs for at most $T(n)$ steps, so $M^{\prime}$ needs at most $\lceil T(n)/m \rceil$ rounds. Each round takes 6 steps of $M^{\prime}$, so Phase 2 takes at most $6\lceil T(n)/m \rceil \le \frac{6T(n)}{m} + 6$ steps. Phase 1 takes $O(n)$ steps. So $M^{\prime}$ takes at most $\frac{6T(n)}{m} + O(n)$ steps in total. With $m = 6r$ this is $\frac{T(n)}{r} + O(n)$. Since every round simulates $m$ steps of $M$ exactly, $M^{\prime}$ halts with the same answer as $M$, so $M^{\prime}$ decides $L$.

There is an analogous result for space.

Theorem — Space Compression Theorem

Let $T : \mathbb{N} \rightarrow \mathbb{N}$ be a space function. Let $r \in \mathbb{N}$ be a positive integer. If there is a TM $M$ that decides $L \in \Sigma^*$ in space $S$, then there exists another TM $M^{\prime}$ that decides $L$ in $\frac{S}{r}$ space, where $n$ is the size of the input $x \in L$.

The proof of this theorem is essentially the same as for the time speedup theorem, except that we don’t need to compress the input in this case, and hence save the additional $O(n)$ term in the statement of the time speedup theorem.

A fundamental goal of complexity theory is to establish hierarchies. We want to decide if a given language requires more time and space than another, thereby establishing the complexity of that language. Ideally we would like to prove statements such as $$T = o(T^{\prime}) \implies \mathsf{DTIME}(T) \subset \mathsf{DTIME}(T^{\prime}) .$$ However, a highly non-intuitive result known as the gap theorem shows that this fails for some $T$.

Theorem — Gap Theorem, Informal

Let $f : \mathbb{N} \to \mathbb{N}$ be a total computable function with $f(n) \ge n$ for all $n$. Then there exist total computable functions $T, S : \mathbb{N} \to \mathbb{N}$ such that $$\mathsf{DTIME}(T) = \mathsf{DTIME}(f \circ T) \quad\text{and}\quad \mathsf{DSPACE}(S) = \mathsf{DSPACE}(f \circ S) .$$

Here $f \circ T$ denotes the function $n \mapsto f(T(n))$. Taking $f(n) = 2^n$, we get the surprising consequence that there are a time bound $T$ and a space bound $S$ with $\mathsf{DTIME}(2^T) = \mathsf{DTIME}(T)$ and $\mathsf{DSPACE}(2^S) = \mathsf{DSPACE}(S)$, where $2^T$ denotes $n \mapsto 2^{T(n)}$.

However, for time-constructible bounds we can prove a hierarchy theorem, so for $f(n) = 2^n$ the time bound $T$ given by the gap theorem cannot be time-constructible. However, for “nice looking” time bounds, we can construct a hierarchy.

Definition

A time bound $T: \mathbb{N} \rightarrow \mathbb{N}$ is time constructible if there exits a TM $M$ which, given a string $1^n$ as input, outputs the binary representation of $T(n)$ in $O(T(n))$ time.

Remark

The above definition just states that the above time bounds are efficiently computable. It is easy to verify that the bounds $n, n^k, 2^n, 2^{n^k}$ are all time constructible (do it as an exercise).

Theorem — Time Hierarchy Theorem

Let $T, T^{\prime}: \mathbb{N} \rightarrow \mathbb{N}$ s.t $T^{\prime}$ is time constructible and $T\log{}T = o(T^{\prime})$. Then $\mathsf{DTIME}(T) \subset \mathsf{DTIME}(T^{\prime})$. A similar statement can be made for space hierarchies, but we only need $S = o(S’)$.
