The setup: we have \(K\) memory cells and a public computer program that only performs reads from memory for \(T\) time steps/cycles. We want to verify that the prover read from memory correctly at each time step. That is, we want to verify that for every time step \(j \in [T]\), if the program is meant to read from cell \(k\), then the value returned by the program is the same as the value in memory cell \(k\).

See Figure below

We do this using the shout protocol.

Throughout this note we will use index \(j\) to index time steps, and \(k\) to index memory cells. We also abuse notation use \(j \in [T]\) and \(j \in \{ 0, 1\}^{\log_2 T}\) interchangeably. It should be quite easy to tell from the context. Also \(T\) and \(K\) are represented as field elements in the actual implementation, so it will be useful to think of them as such.

The Shout Protocol

Consider the following functions1 which describe the program trace and the memory state:

  • \(\mathsf{ra}: \{ 0, 1\}^{\log T} \times \{ 0, 1\}^{\log K} \rightarrow \{ 0, 1\}\) where \(\mathsf{ra}(j, k) = 1\) if we read memory location \(k\) at time step \(j\), and for all \(k' \neq k\) we have \(\mathsf{ra}(j, k') = 0\). This is an indicator encoding for the function \(\mathsf{raf}: \{ 0, 1\}^T \rightarrow [K]\), where \(\mathsf{raf}(j)\) is equal to the memory location read at tiem \(j\)

  • \(\mathsf{Val}: \{ 0, 1\}^{\log K} \rightarrow \mathbb{F}\) where \(\mathsf{Val}(k)\) is the value stored in memory location \(k\).

The prover claims that at each time step the vector \(\mathsf{rv}\) describes the values that were read from memory.

  • \(\mathsf{rv}: \{ 0, 1\}^{\log T} \rightarrow \mathbb{F}\) where \(\mathsf{rv}(j)\) represents the value the prover claims the program should return at time step \(j\).

Assumption: The verifying party has the ability to evaluate the multi-linear extensions of the above vectors at a single random location of their choosing.

Assuming for a minute that \(\mathsf{ra}\) is one-encoded as described above, then checking if the prover did all reads correctly accounts to checking:

\[ \begin{align} rv(j) &= \sum_{k \in \{ 0, 1\}^{\log K}} \widetilde{\mathsf{ra}}(j,k)\widetilde{Val}(k) & \forall j \in \{ 0, 1\}^T \\ \end{align} \]

To check if the LHS and RHS are equivalent as polynomials, we sample \(\textcolor{green}{r_{\text{cycle}}}\xleftarrow[]{\$}\mathbb{F}^T\), and simply check

\[ \begin{align} rv(\textcolor{green}{r_{\text{cycle}}}) &= \sum_{k \in \{ 0, 1\}^{\log K}} \widetilde{\mathsf{ra}}(\textcolor{green}{r_{\text{cycle}}},k)\widetilde{\mathsf{Val}}(k) \\ &= \sum_{k \in \{ 0, 1\}^{\log K}} \widetilde{\mathsf{Val}}(k) \sum_{j \in \{ 0, 1\}^T} \mathsf{eq}\left(\textcolor{green}{r_{\text{cycle}}}, j\right)\, \widetilde{\mathsf{ra}}(j, k)\, \end{align} \]

The Actual Assumption

The verifying party cannot actually evaluate the polynomials at random locations. Rather, the prover commits to \(\mathsf{ra}\), \(\mathsf{rv}\) and \(\mathsf{Val}\). And then sends an evaluation proof for these polynomials at an opening location of their choosing. To commit to each row of \(\mathsf{ra}\), we need a size \(K\) commitment key2. If \(K\) is large – this is a giant pain in the arse, and can be very inefficient. So we do the following, we write memory location \(k \in [K]\) using \(d\) digits in base \(N = K^{1/d}\).

This splits \(\mathsf{ra}\) into \(d\) functions \(\mathsf{ra}_1, \ldots, \mathsf{ra}_d\).

\[\mathsf{ra}(j, k) = \mathsf{ra}_1(j, k_1) \times \ldots \mathsf{ra}_i(j, k_i) \ldots \mathsf{ra}_d(j, k_d)\]

Now for each \(j \in [T]\), we need the prover to commit to \(d\) vectors with commitment key size \(N\). So if \(d=2\), the commitment key is \(\sqrt{K}\). So faster commitments – but shittier sumcheck

\[ \begin{align} \mathsf{rv}(\textcolor{green}{r_{\text{cycle}}}) &= \sum_{k \in \{ 0, 1\}^{\log K}} \widetilde{\mathsf{ra}}(\textcolor{green}{r_{\text{cycle}}},k)\, \widetilde{\mathsf{Val}}(k) \\ &= \sum_{k_1, \ldots, k_d \in \Big(\{ 0, 1\}^{\log N}\Big)^d} \widetilde{\mathsf{Val}}(k_1||k_2||\ldots||k_d) \sum_{j \in \{ 0, 1\}^T} \mathsf{eq}\left(\textcolor{green}{r_{\text{cycle}}}, j\right)\, \prod_{i=1}^d \widetilde{\mathsf{ra}_i}(j, k_i)\, \end{align} \]
