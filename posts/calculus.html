Reviewing The Sum-Check Protocol

frac:

Below we provide a brief summary of the sum-check protocol used in Jolt. For a detailed description of the sum-check optimisations in jolt refer to this post.

We have some multilinear polynomial \(g(X_1, \ldots, X_\ell)\), and the prover wants to convince the verifier of the claim that \(c = \sum_{(W_1, \ldots, W_\ell) \in \{0, 1\}^{\ell}} g(W_1, \ldots, W_\ell)\).

The protocol proceeds in \(\ell\) rounds:

  1. In the first round the prover sends to the verifier \(c, p_1(X_1)\).

  2. The verifier does a check. If all is happy.

  3. The verifier sends \(r_1 \samples S\)

  4. The prover coputers \(g(r_1, X_2, \ldots, X_\ell)\) – binding

  5. New message \(p_2(X_2)\)

  6. Verifier checks if $p_2(0) + p_2(1) = + $
