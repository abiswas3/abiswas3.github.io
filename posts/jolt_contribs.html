Contributions On Jolt So far

Merging of the next streaming PR would move me to top 7 jolt contributors of all time based on Github statistics. This does not include the arkworks-algebra contributions.

Sum-check Streaming

  • Designed and implemented the first generalised sum-check for space constrained sum-checks with streaming schedules
  • Blog Posts: Intro to streaming sumchecks - code walk through, Benchmarking current progress: No performance loss when schedule is linear.
  • Pull Request Active – waiting on Lazy iteration being completed for a merge.

Small challenges in Jolt

  • Summary: Leads to 1.6x-2x speedup of Multilinear polynomial binding.
  • Blog Post
  • Pull Request merged into main
  • Co-author on new paper on sum-check optimisations. Overleaf

Faster Polynomial Evaluation

  • 2x speedup on dot product styled MLE with split-eq evals. Blog
  • Additionally introduced the idea of tracked field elements that allow us to track exact arithmetic operations across jolt to make sure we are optimal. Tracked Datatypes
  • PR merged into main

Msms Take I

Better parallelisation for multi-linear scalar multiplication, and latest changes from ark works pulled in to the Jolt fork – Pull Request – merged into main

NOTE: These showed 10x speedup in micro-benches, but end to the speedups seemed to disappear. A detailed deep dive of this was delayed at the time. The outstanding conjecture is that rayon code for MSMs is sub-optimal, but other developers have not been able to yet come to a clear definitive conclusion that this is indeed the case. Moved on to more pressing projects since then. THIS IS SOMETHING THAT COULD DESERVE ATTENTION AGAIN

Montgomery Multiplication

  • Pull Requests: not merged into mainline as there is no clear evidence these algorithms are faster.
  • Generalised Yuval’s algorithm to a family of algorithms – and identified the tradeoff between branch misses and number of multiplication operations, that was previously not mentioned in prior research.
  • Delayed for now: With all the recent small value optimisations from streaming and binding, it might be possible to bring some of these optimisations back into main.
