Overview

Goal: Generate the first-round polynomial for Stage 1 outer sumcheck:

\[s_1(Y) = L(\tau_{high}, Y) \cdot t_1(Y)\]

Where: - \(Y\) is the constraint index treated as a continuous variable - \(t_1(Y)\) is the “base polynomial” evaluated at extended domain points - \(L(\tau_{high}, Y)\) is a Lagrange masking polynomial - The result is a degree-24 polynomial with 25 coefficients

Key insight: The R1CS property \(Az \cdot Bz = 0\) holds at integer constraint indices {0, 1, …, 18}, but when we treat the constraint index as a continuous variable and interpolate, \(Az(Y) \cdot Bz(Y)\) becomes non-zero at non-integer points.

The optimization: Only compute \(t_1(Y)\) at points where it’s non-zero (8 extended points), use Lagrange interpolation to reconstruct the full polynomial.

The 19 R1CS Constraints

Each constraint has the form: Az · Bz = 0

Constraint 0: RamAddrEqRs1PlusImmIfLoadStore

Az = Load + Store
Bz = RamAddress - (Rs1Value + Imm)

Meaning: If this is a load or store, RAM address must equal Rs1 + Imm

Constraint 1: RamAddrEqZeroIfNotLoadStore

Az = 1 - Load - Store
Bz = RamAddress

Meaning: If NOT load/store, RAM address must be zero

Constraint 2: RamReadEqRamWriteIfLoad

Az = Load
Bz = RamReadValue - RamWriteValue

Meaning: On load, read value equals write value (memory consistency)

Constraint 3: RamReadEqRdWriteIfLoad

Az = Load
Bz = RamReadValue - RdWriteValue

Meaning: On load, RAM read value goes to destination register

Constraint 4: Rs2EqRamWriteIfStore

Az = Store
Bz = Rs2Value - RamWriteValue

Meaning: On store, Rs2 value is what gets written to memory

Constraint 5: LeftLookupZeroUnlessAddSubMul

Az = AddOperands + SubtractOperands + MultiplyOperands
Bz = LeftLookupOperand

Meaning: For add/sub/mul, left lookup is zero (only right lookup used)

Constraint 6: LeftLookupEqLeftInputOtherwise

Az = 1 - AddOperands - SubtractOperands - MultiplyOperands
Bz = LeftLookupOperand - LeftInstructionInput

Meaning: For non-add/sub/mul, left lookup equals left input

Constraint 7: RightLookupAdd

Az = AddOperands
Bz = RightLookupOperand - (LeftInstructionInput + RightInstructionInput)

Meaning: For addition, right lookup equals sum of inputs

Constraint 8: RightLookupSub

Az = SubtractOperands
Bz = RightLookupOperand - (LeftInstructionInput - RightInstructionInput + 2^64)

Meaning: For subtraction, right lookup equals difference (with 2’s complement adjustment)

Constraint 9: RightLookupEqProductIfMul

Az = MultiplyOperands
Bz = RightLookupOperand - Product

Meaning: For multiplication, right lookup equals product

Constraint 10: RightLookupEqRightInputOtherwise

Az = 1 - AddOperands - SubtractOperands - MultiplyOperands - Advice
Bz = RightLookupOperand - RightInstructionInput

Meaning: Otherwise, right lookup equals right input

Constraint 11: AssertLookupOne

Az = Assert
Bz = LookupOutput - 1

Meaning: Assert instructions require lookup output equals 1

Constraint 12: RdWriteEqLookupIfWriteLookupToRd

Az = WriteLookupOutputToRD
Bz = RdWriteValue - LookupOutput

Meaning: When writing lookup to Rd, Rd write value equals lookup output

Constraint 13: RdWriteEqPCPlusConstIfWritePCtoRD

Az = WritePCtoRD
Bz = RdWriteValue - (UnexpandedPC + 4 - 2*IsCompressed)

Meaning: When writing PC to Rd (jumps), Rd gets PC+4 (or PC+2 if compressed)

Constraint 14: NextUnexpPCEqLookupIfShouldJump

Az = ShouldJump
Bz = NextUnexpandedPC - LookupOutput

Meaning: When jumping, next PC equals jump target from lookup

Constraint 15: NextUnexpPCEqPCPlusImmIfShouldBranch

Az = ShouldBranch
Bz = NextUnexpandedPC - (UnexpandedPC + Imm)

Meaning: When branching, next PC equals current PC + branch offset

Constraint 16: NextUnexpPCUpdateOtherwise

Az = 1 - ShouldBranch - Jump
Bz = NextUnexpandedPC - (UnexpandedPC + 4 - 4*DoNotUpdate - 2*IsCompressed)

Meaning: When not jumping/branching, PC advances by 4 (or 2 if compressed, or 0 if paused)

Constraint 17: NextPCEqPCPlusOneIfInline

Az = VirtualInstruction
Bz = NextPC - (PC + 1)

Meaning: For virtual (inlined) instructions, expanded PC increments by 1

Constraint 18: MustStartSequenceFromBeginning

Az = NextIsVirtual - NextIsFirstInSequence
Bz = DoNotUpdateUnexpandedPC - 1

Meaning: Virtual instruction sequences must start from beginning

General Explanation

The Base Polynomial t₁(Y)

For a given cycle, we want to compute:

\[t_1(Y) = \sum_{x_{in}} eq(\tau_{in}, x_{in}) \cdot Az(x_{in}, Y) \cdot Bz(x_{in}, Y)\]

Where: - \(Y\) is the constraint index (treated as continuous) - \(x_{in}\) indexes over inner variables - Az and Bz are evaluated by plugging witness values into constraint formulas

The Domain Structure

Constraints are split into two groups: - Group 0 (first 10 constraints): Indices {0, 1, 2, …, 9} - This is the “base window” centered at 0 - At these integer points: Az · Bz = 0 (by R1CS property)

  • Group 1 (last 9 constraints): Indices {10, 11, 12, …, 18}

For univariate skip, we treat Group 0 as the base: - Base window: {-4, -3, -2, -1, 0, 1, 2, 3, 4} - These map to constraints {0-8} - At these points, \(t_1(Y) = 0\) (since Az · Bz = 0)

  • Extended domain: {-8, -7, -6, -5, 5, 6, 7, 8} - The 8 points outside base window
    • At these points, \(t_1(Y) \neq 0\) (interpolation makes it non-zero)

Why is t₁(Y) zero in the base window?

Because at integer constraint indices, the R1CS property holds: Az(i) · Bz(i) = 0 for all cycles.

Why is t₁(Y) non-zero at extended points?

When we treat Y as continuous and interpolate, Az(Y) and Bz(Y) become polynomials. At non-integer Y values, their product is generally non-zero.

The Two Groups

The 19 constraints are processed in two separate groups:

Group 0 (Constraints 0-8): - Maps to base window {-4, …, 4} - Az values are booleans (0 or 1) - Bz values fit in i128

Group 1 (Constraints 9-18): - Treated as part of the extended/remaining computation - Az values are small integers (u8) - Bz values require S160 (wider arithmetic)

Step-by-Step Process

Phase 1: Compute Extended Domain Evaluations

For each of the 8 extended points (e.g., Y = -8, -7, …, -5, 5, …, 8):

Step 1.1: Compute Lagrange Shift Coefficients

For target point Y (e.g., Y = 5), compute coefficients that let us interpolate from base window {-4, …, 4} to target Y:

coeffs = lagrange_shift_coefficients(
    from_points = [-4, -3, -2, -1, 0, 1, 2, 3, 4],  # base window
    to_point = 5                                      # extended target
)
# Returns 9 coefficients [c₀, c₁, c₂, ..., c₈]

These coefficients satisfy: \[f(5) = \sum_{i=-4}^{4} coeffs[i+4] \cdot f(i)\]

Step 1.2: For Each Cycle

for cycle in 0..num_cycles:
    # Get witness values for this cycle
    row = trace[cycle]
    
    # Evaluate Az and Bz at discrete constraint indices
    az_group0 = eval_az_first_group(row)   # 9 boolean values for constraints 0-8
    bz_group0 = eval_bz_first_group(row)   # 9 i128 values for constraints 0-8
    
    # Interpolate Az to extended point Y using Lagrange coefficients
    az_at_Y = sum(coeffs[i] * az_group0[i] for i in 0..9)
    
    # Interpolate Bz to extended point Y
    bz_at_Y = sum(coeffs[i] * bz_group0[i] for i in 0..9)
    
    # Compute product
    product = az_at_Y * bz_at_Y
    
    # Weight by equality polynomials
    eq_out = eq(tau_out, cycle_index)
    eq_in = eq(tau_in, inner_vars)
    
    # Accumulate
    t1[Y] += eq_out * eq_in * product

Result: 8 field element values = t₁(Y) evaluated at the 8 extended points

Phase 2: Reconstruct Full Polynomial

Step 2.1: Combine Base and Extended Evaluations

t1_full_evals = [0; 17]  # Size = 2*8 + 1 = 17 (symmetric window {-8, ..., 8})

# Base window (all zeros)
t1_full_evals[-4..=4] = [0, 0, 0, 0, 0, 0, 0, 0, 0]  # 9 zeros

# Extended points (computed values)
t1_full_evals[-8] = t1_extended[0]  # Point Y = -8
t1_full_evals[-7] = t1_extended[1]  # Point Y = -7
t1_full_evals[-6] = t1_extended[2]  # Point Y = -6
t1_full_evals[-5] = t1_extended[3]  # Point Y = -5
t1_full_evals[5]  = t1_extended[4]  # Point Y = 5
t1_full_evals[6]  = t1_extended[5]  # Point Y = 6
t1_full_evals[7]  = t1_extended[6]  # Point Y = 7
t1_full_evals[8]  = t1_extended[7]  # Point Y = 8

Step 2.2: Interpolate t₁(Y) to Get Coefficients

t1_coeffs = lagrange_interpolate(t1_full_evals)
# Returns 17 coefficients (degree-16 polynomial)

Now we have \(t_1(Y)\) as a polynomial: \(t_1(Y) = \sum_{i=0}^{16} c_i Y^i\)

Step 2.3: Build Lagrange Masking Polynomial L(τ_high, Y)

# Evaluate Lagrange basis polynomials at challenge tau_high
lagrange_values = [L₀(tau_high), L₁(tau_high), ..., L₈(tau_high)]  # 9 values

# Interpolate to get polynomial coefficients
lagrange_coeffs = lagrange_interpolate(lagrange_values)  # 9 coefficients (degree-8)

This gives us \(L(\tau_{high}, Y)\) that “selects” which constraint group based on \(\tau_{high}\).

Step 2.4: Multiply the Polynomials

s1_coeffs = convolve(lagrange_coeffs, t1_coeffs)
# lagrange: degree 8 (9 coeffs)
# t1: degree 16 (17 coeffs)
# product: degree 8+16 = 24 (25 coeffs)

Convolution formula: \[s_1(Y) = \sum_{i=0}^{24} \left(\sum_{j=0}^{\min(i,8)} L_j \cdot t_{i-j}\right) Y^i\]

Phase 3: Return First-Round Polynomial

return UniPoly { coefficients: s1_coeffs }  # 25 coefficients

This polynomial is sent to the verifier, who evaluates it at challenge point \(r_0\) to continue the sumcheck.

Concrete Example: Cycle 0

Let’s walk through the computation for Cycle 0 at extended point Y = 5.

Cycle 0 Trace Data

Instruction: AUIPC rd=2, imm=4096
Address: 2147483648
Result: rd[2] = PC + imm = 2147483648 + 4096 = 2147487744

Step 1: Extract Witness Values

From the trace:

PC = 2147483648
UnexpandedPC = 2147483648
NextPC = 2147483649 (expanded PC increments)
NextUnexpandedPC = 2147483652 (instruction address advances by 4)

Rs1Value = ? (AUIPC doesn't read Rs1)
Rs2Value = ?
RdWriteValue = 2147487744

RamAddress = 0 (no memory access)
RamReadValue = 0
RamWriteValue = 0

Imm = 4096

LeftInstructionInput = UnexpandedPC = 2147483648 (AUIPC uses PC as left input)
RightInstructionInput = Imm = 4096

LeftLookupOperand = 0 (AUIPC uses AddOperands, so left lookup is 0)
RightLookupOperand = 2147487744 (PC + imm)
LookupOutput = 2147487744

Flags:
  Load = false
  Store = false
  Jump = false
  AddOperands = true (AUIPC internally adds PC + imm)
  SubtractOperands = false
  MultiplyOperands = false
  WriteLookupOutputToRD = true
  VirtualInstruction = false
  IsCompressed = false
  DoNotUpdateUnexpandedPC = false
  Assert = false
  Advice = false

Derived:
  WritePCtoRD = false (Jump && IsRdNotZero = false && true = false)
  ShouldJump = false (Jump && !NextIsNoop = false)
  ShouldBranch = false (Branch && LookupOutput==1 = false)

Step 2: Evaluate Az and Bz for Group 0 (Constraints 0-8)

Constraint 0: RamAddrEqRs1PlusImmIfLoadStore

Az[0] = Load + Store = false + false = 0
Bz[0] = RamAddress - (Rs1Value + Imm) 
      = 0 - (? + 4096) 
      = -? - 4096  # Some negative value

Constraint 1: RamAddrEqZeroIfNotLoadStore

Az[1] = 1 - Load - Store = 1 - 0 - 0 = 1
Bz[1] = RamAddress = 0

Constraint 2: RamReadEqRamWriteIfLoad

Az[2] = Load = 0
Bz[2] = RamReadValue - RamWriteValue = 0 - 0 = 0

Constraint 3: RamReadEqRdWriteIfLoad

Az[3] = Load = 0
Bz[3] = RamReadValue - RdWriteValue = 0 - 2147487744

Constraint 4: Rs2EqRamWriteIfStore

Az[4] = Store = 0
Bz[4] = Rs2Value - RamWriteValue = ? - 0

Constraint 5: LeftLookupZeroUnlessAddSubMul

Az[5] = AddOperands + SubtractOperands + MultiplyOperands
      = true + false + false = 1
Bz[5] = LeftLookupOperand = 0

Constraint 6: LeftLookupEqLeftInputOtherwise

Az[6] = 1 - AddOperands - SubtractOperands - MultiplyOperands
      = 1 - 1 - 0 - 0 = 0
Bz[6] = LeftLookupOperand - LeftInstructionInput
      = 0 - 2147483648

Constraint 7: RightLookupAdd

Az[7] = AddOperands = 1
Bz[7] = RightLookupOperand - (LeftInstructionInput + RightInstructionInput)
      = 2147487744 - (2147483648 + 4096)
      = 2147487744 - 2147487744 = 0

Constraint 8: RightLookupSub

Az[8] = SubtractOperands = 0
Bz[8] = (not evaluated, constraint inactive)

Summary for Group 0:

Az_group0 = [0, 1, 0, 0, 0, 1, 0, 1, 0]  # Boolean values
Bz_group0 = [?, 0, 0, ?, ?, 0, ?, 0, ?]  # i128 values (? = some value)

Key observation: Az[i] · Bz[i] = 0 for all i! - Constraint 1: Az=1, Bz=0 → product = 0 - Constraint 5: Az=1, Bz=0 → product = 0 - Constraint 7: Az=1, Bz=0 → product = 0 - All others: Az=0 → product = 0

Step 3: Interpolate to Extended Point Y = 5

Get Lagrange coefficients for interpolating from base window {-4, -3, -2, -1, 0, 1, 2, 3, 4} to target Y = 5:

coeffs = lagrange_shift_coefficients(
    from_window = [-4, -3, -2, -1, 0, 1, 2, 3, 4],
    to_point = 5
)

These coefficients (computed using Lagrange interpolation formula) might look something like:

coeffs ≈ [c₀, c₁, c₂, c₃, c₄, c₅, c₆, c₇, c₈]
# Exact values depend on field arithmetic

Interpolate Az to Y=5:

Az(Y=5) = sum(coeffs[i] * Az_group0[i] for i in 0..9)
        = c₀*0 + c₁*1 + c₂*0 + c₃*0 + c₄*0 + c₅*1 + c₆*0 + c₇*1 + c₈*0
        = c₁ + c₅ + c₇

Interpolate Bz to Y=5:

Bz(Y=5) = sum(coeffs[i] * Bz_group0[i] for i in 0..9)
        = c₀*Bz[0] + c₁*0 + c₂*0 + c₃*Bz[3] + c₄*Bz[4] + c₅*0 + c₆*Bz[6] + c₇*0 + c₈*Bz[8]
        = c₀*Bz[0] + c₃*Bz[3] + c₄*Bz[4] + c₆*Bz[6] + c₈*Bz[8]

Compute product:

product = Az(Y=5) * Bz(Y=5)
        = (c₁ + c₅ + c₇) * (c₀*Bz[0] + c₃*Bz[3] + c₄*Bz[4] + c₆*Bz[6] + c₈*Bz[8])

This is non-zero! Even though Az·Bz = 0 at all integer points, when we interpolate to Y=5, the product becomes non-zero.

Step 4: Weight by Equality Polynomials

eq_out = eq(tau_out, cycle=0) * R² (Montgomery scaling)
eq_in = eq(tau_in, inner_variables)

contribution = eq_out * eq_in * product

Step 5: Accumulate

t1[Y=5] += contribution

This process repeats for: - All cycles (accumulating each cycle’s contribution) - All 8 extended points (Y = -8, -7, -6, -5, 5, 6, 7, 8)

The Math Behind Lagrange Interpolation

Why Does This Work?

Lagrange interpolation theorem: Given n+1 points (x₀, y₀), (x₁, y₁), …, (xₙ, yₙ), there exists a unique polynomial p(x) of degree ≤ n that passes through all these points.

In our case: - We know Az at 9 points: {-4, -3, -2, -1, 0, 1, 2, 3, 4} - We want Az at point Y=5 - We use the Lagrange basis to “extend” these 9 values to the target point

Lagrange Basis Polynomials

For base points {-4, -3, -2, -1, 0, 1, 2, 3, 4}, the Lagrange basis polynomial for point i is:

\[L_i(Y) = \prod_{j \neq i} \frac{Y - x_j}{x_i - x_j}\]

Properties: - \(L_i(x_j) = \delta_{ij}\) (equals 1 at xᵢ, 0 at all other xⱼ) - Any polynomial through the points can be written as: \(p(Y) = \sum_i y_i L_i(Y)\)

Evaluation at target Y=5: \[Az(5) = \sum_{i=0}^{8} Az(x_i) \cdot L_i(5)\]

The Lagrange shift coefficients are just: coeffs[i] = Lᵢ(5)

Why Doesn’t t₁(Y) = 0 Everywhere?

At integer points: Az(i) · Bz(i) = 0 for all i (R1CS property)

At non-integer point Y=5: - Az(5) = interpolated value ≠ necessarily 0 - Bz(5) = interpolated value ≠ necessarily 0 - Product Az(5) · Bz(5) is generally non-zero

Intuition: The polynomial Az(Y) · Bz(Y) has zeros at integer points {0, 1, …, 8}, but that doesn’t mean it’s zero everywhere. Between and beyond these points, it can (and does) take non-zero values.

Example with simple polynomials: - Let Az(Y) = Y and Bz(Y) = 1 - Y - At Y=0: Az·Bz = 0·1 = 0 ✓ - At Y=1: Az·Bz = 1·0 = 0 ✓ - At Y=0.5: Az·Bz = 0.5·0.5 = 0.25 ≠ 0 ✗

The R1CS constraints ensure Az·Bz = 0 at discrete points, but interpolation creates a polynomial that’s non-zero elsewhere.

Summary

The univariate skip optimization:

  1. Exploits sparsity: t₁(Y) = 0 in base window {-4, …, 4} due to R1CS property
  2. Computes at extended points: Only 8 evaluations needed where t₁(Y) ≠ 0
  3. Uses Lagrange interpolation: To “extend” discrete Az/Bz values to continuous points
  4. Reconstructs full polynomial: Combine zeros + computed values, then interpolate
  5. Multiplies by Lagrange mask: L(τ_high, Y) to get final s₁(Y)
  6. Result: Degree-24 polynomial (25 coefficients) for first sumcheck round

Cost savings: - Without optimization: O(num_cycles × 2^(constraint_vars)) - With optimization: O(num_cycles × 8 extended points) = Linear!

This is what makes Jolt’s Stage 1 sumcheck practical at scale.
