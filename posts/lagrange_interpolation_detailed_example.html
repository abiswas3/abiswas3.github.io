Detailed Numerical Example: Lagrange Interpolation in Univariate Skip

Overview

This document provides a concrete numerical walkthrough of how Lagrange interpolation works in the univariate skip optimization, with actual coefficient calculations and multiple cycle examples.

Part 1: Computing Lagrange Shift Coefficients

The Setup

Base window (Group 0 constraints): {-4, -3, -2, -1, 0, 1, 2, 3, 4}
Target extended point: Y = 5

We want to compute coefficients such that:

\[f(5) = \sum_{i=-4}^{4} c_i \cdot f(i)\]

Lagrange Basis Formula

For each base point \(x_i\) in {-4, -3, -2, -1, 0, 1, 2, 3, 4}, the Lagrange basis polynomial is:

\[L_i(Y) = \prod_{j \neq i} \frac{Y - x_j}{x_i - x_j}\]

The coefficient \(c_i = L_i(5)\)

Computing Each Coefficient

Coefficient for i = -4 (c₀)

\[L_{-4}(5) = \frac{(5-(-3))(5-(-2))(5-(-1))(5-0)(5-1)(5-2)(5-3)(5-4)}{(-4-(-3))(-4-(-2))(-4-(-1))(-4-0)(-4-1)(-4-2)(-4-3)(-4-4)}\]

Numerator: \[= (8)(7)(6)(5)(4)(3)(2)(1) = 40320\]

Denominator: \[= (-1)(-2)(-3)(-4)(-5)(-6)(-7)(-8) = 40320\]

\[c_0 = L_{-4}(5) = \frac{40320}{40320} = 1\]

Coefficient for i = -3 (c₁)

\[L_{-3}(5) = \frac{(5-(-4))(5-(-2))(5-(-1))(5-0)(5-1)(5-2)(5-3)(5-4)}{(-3-(-4))(-3-(-2))(-3-(-1))(-3-0)(-3-1)(-3-2)(-3-3)(-3-4)}\]

Numerator: \[= (9)(7)(6)(5)(4)(3)(2)(1) = 45360\]

Denominator: \[= (1)(-1)(-2)(-3)(-4)(-5)(-6)(-7) = -5040\]

\[c_1 = L_{-3}(5) = \frac{45360}{-5040} = -9\]

Coefficient for i = -2 (c₂)

\[L_{-2}(5) = \frac{(5-(-4))(5-(-3))(5-(-1))(5-0)(5-1)(5-2)(5-3)(5-4)}{(-2-(-4))(-2-(-3))(-2-(-1))(-2-0)(-2-1)(-2-2)(-2-3)(-2-4)}\]

Numerator: \[= (9)(8)(6)(5)(4)(3)(2)(1) = 51840\]

Denominator: \[= (2)(1)(-1)(-2)(-3)(-4)(-5)(-6) = 1440\]

\[c_2 = L_{-2}(5) = \frac{51840}{1440} = 36\]

Coefficient for i = -1 (c₃)

\[L_{-1}(5) = \frac{(5-(-4))(5-(-3))(5-(-2))(5-0)(5-1)(5-2)(5-3)(5-4)}{(-1-(-4))(-1-(-3))(-1-(-2))(-1-0)(-1-1)(-1-2)(-1-3)(-1-4)}\]

Numerator: \[= (9)(8)(7)(5)(4)(3)(2)(1) = 60480\]

Denominator: \[= (3)(2)(1)(-1)(-2)(-3)(-4)(-5) = -720\]

\[c_3 = L_{-1}(5) = \frac{60480}{-720} = -84\]

Coefficient for i = 0 (c₄)

\[L_0(5) = \frac{(5-(-4))(5-(-3))(5-(-2))(5-(-1))(5-1)(5-2)(5-3)(5-4)}{(0-(-4))(0-(-3))(0-(-2))(0-(-1))(0-1)(0-2)(0-3)(0-4)}\]

Numerator: \[= (9)(8)(7)(6)(4)(3)(2)(1) = 72576\]

Denominator: \[= (4)(3)(2)(1)(-1)(-2)(-3)(-4) = 576\]

\[c_4 = L_0(5) = \frac{72576}{576} = 126\]

Coefficient for i = 1 (c₅)

\[L_1(5) = \frac{(5-(-4))(5-(-3))(5-(-2))(5-(-1))(5-0)(5-2)(5-3)(5-4)}{(1-(-4))(1-(-3))(1-(-2))(1-(-1))(1-0)(1-2)(1-3)(1-4)}\]

Numerator: \[= (9)(8)(7)(6)(5)(3)(2)(1) = 90720\]

Denominator: \[= (5)(4)(3)(2)(1)(-1)(-2)(-3) = -720\]

\[c_5 = L_1(5) = \frac{90720}{-720} = -126\]

Coefficient for i = 2 (c₆)

\[L_2(5) = \frac{(5-(-4))(5-(-3))(5-(-2))(5-(-1))(5-0)(5-1)(5-3)(5-4)}{(2-(-4))(2-(-3))(2-(-2))(2-(-1))(2-0)(2-1)(2-3)(2-4)}\]

Numerator: \[= (9)(8)(7)(6)(5)(4)(2)(1) = 120960\]

Denominator: \[= (6)(5)(4)(3)(2)(1)(-1)(-2) = 1440\]

\[c_6 = L_2(5) = \frac{120960}{1440} = 84\]

Coefficient for i = 3 (c₇)

\[L_3(5) = \frac{(5-(-4))(5-(-3))(5-(-2))(5-(-1))(5-0)(5-1)(5-2)(5-4)}{(3-(-4))(3-(-3))(3-(-2))(3-(-1))(3-0)(3-1)(3-2)(3-4)}\]

Numerator: \[= (9)(8)(7)(6)(5)(4)(3)(1) = 181440\]

Denominator: \[= (7)(6)(5)(4)(3)(2)(1)(-1) = -5040\]

\[c_7 = L_3(5) = \frac{181440}{-5040} = -36\]

Coefficient for i = 4 (c₈)

\[L_4(5) = \frac{(5-(-4))(5-(-3))(5-(-2))(5-(-1))(5-0)(5-1)(5-2)(5-3)}{(4-(-4))(4-(-3))(4-(-2))(4-(-1))(4-0)(4-1)(4-2)(4-3)}\]

Numerator: \[= (9)(8)(7)(6)(5)(4)(3)(2) = 362880\]

Denominator: \[= (8)(7)(6)(5)(4)(3)(2)(1) = 40320\]

\[c_8 = L_4(5) = \frac{362880}{40320} = 9\]

Summary of Lagrange Coefficients for Y=5

coeffs = [1, -9, 36, -84, 126, -126, 84, -36, 9]

Verification: These satisfy \(\sum_i c_i = 0\) except at the interpolation point.

Pattern: Notice the symmetric structure: coeffs[i] = coeffs[8-i] (up to sign changes)

Part 2: Detailed Example with Cycle 0

Cycle 0 Witness Values (AUIPC rd=2, imm=4096)

# From trace
PC = 2147483648
UnexpandedPC = 2147483648
NextPC = 2147483649
NextUnexpandedPC = 2147483652
RdWriteValue = 2147487744  # PC + imm

RamAddress = 0
RamReadValue = 0
RamWriteValue = 0

LeftInstructionInput = 2147483648  # UnexpandedPC
RightInstructionInput = 4096       # Imm

LeftLookupOperand = 0
RightLookupOperand = 2147487744    # Result
LookupOutput = 2147487744

# Flags
AddOperands = true
(all other flags false except standard ones)

Evaluate Az for Group 0 (Constraints 0-8)

Az[0] = Load + Store = 0 + 0 = 0
Az[1] = 1 - Load - Store = 1 - 0 - 0 = 1
Az[2] = Load = 0
Az[3] = Load = 0
Az[4] = Store = 0
Az[5] = AddOperands + SubtractOperands + MultiplyOperands = 1 + 0 + 0 = 1
Az[6] = 1 - AddOperands - SubtractOperands - MultiplyOperands = 1 - 1 - 0 - 0 = 0
Az[7] = AddOperands = 1
Az[8] = SubtractOperands = 0

Result: Az = [0, 1, 0, 0, 0, 1, 0, 1, 0]

Evaluate Bz for Group 0 (Constraints 0-8)

Bz[0] = RamAddress - (Rs1Value + Imm) 
      = 0 - (unknown + 4096)
      # Let's say Rs1Value was 0 initially
      = 0 - 4096 = -4096

Bz[1] = RamAddress = 0

Bz[2] = RamReadValue - RamWriteValue = 0 - 0 = 0

Bz[3] = RamReadValue - RdWriteValue 
      = 0 - 2147487744 = -2147487744

Bz[4] = Rs2Value - RamWriteValue
      = unknown - 0
      # Let's say Rs2Value was 0
      = 0

Bz[5] = LeftLookupOperand = 0

Bz[6] = LeftLookupOperand - LeftInstructionInput
      = 0 - 2147483648 = -2147483648

Bz[7] = RightLookupOperand - (LeftInstructionInput + RightInstructionInput)
      = 2147487744 - (2147483648 + 4096)
      = 2147487744 - 2147487744 = 0

Bz[8] = (not computed, constraint inactive) = 0

Result: Bz = [-4096, 0, 0, -2147487744, 0, 0, -2147483648, 0, 0]

Verify Az · Bz = 0 at All Integer Points

Az[0] * Bz[0] = 0 * (-4096) = 0 ✓
Az[1] * Bz[1] = 1 * 0 = 0 ✓
Az[2] * Bz[2] = 0 * 0 = 0 ✓
Az[3] * Bz[3] = 0 * (-2147487744) = 0 ✓
Az[4] * Bz[4] = 0 * 0 = 0 ✓
Az[5] * Bz[5] = 1 * 0 = 0 ✓
Az[6] * Bz[6] = 0 * (-2147483648) = 0 ✓
Az[7] * Bz[7] = 1 * 0 = 0 ✓
Az[8] * Bz[8] = 0 * 0 = 0 ✓

All products are zero! This is the R1CS property.

Interpolate Az to Y=5

Using coefficients [1, -9, 36, -84, 126, -126, 84, -36, 9]:

Az(5) = c₀*Az[0] + c₁*Az[1] + c₂*Az[2] + c₃*Az[3] + c₄*Az[4] 
      + c₅*Az[5] + c₆*Az[6] + c₇*Az[7] + c₈*Az[8]
      
      = 1*0 + (-9)*1 + 36*0 + (-84)*0 + 126*0 
      + (-126)*1 + 84*0 + (-36)*1 + 9*0
      
      = 0 - 9 + 0 + 0 + 0 - 126 + 0 - 36 + 0
      
      = -171

Interpolate Bz to Y=5

Bz(5) = c₀*Bz[0] + c₁*Bz[1] + c₂*Bz[2] + c₃*Bz[3] + c₄*Bz[4] 
      + c₅*Bz[5] + c₆*Bz[6] + c₇*Bz[7] + c₈*Bz[8]
      
      = 1*(-4096) + (-9)*0 + 36*0 + (-84)*(-2147487744) + 126*0
      + (-126)*0 + 84*(-2147483648) + (-36)*0 + 9*0
      
      = -4096 + 0 + 0 + 180389290496 + 0 + 0 - 180388786432 + 0 + 0
      
      = -4096 + 180389290496 - 180388786432
      
      = 499968

Compute Product at Y=5

product = Az(5) * Bz(5) = (-171) * 499968 = -85494528

This is non-zero! Even though Az(i) · Bz(i) = 0 for all integer i, when we interpolate to Y=5, we get a non-zero product.

Why Is This Non-Zero?

At integer constraint indices: - Az and Bz are carefully constructed so their product is always 0 - This is the R1CS property

At non-integer Y=5: - We’re interpolating polynomials Az(Y) and Bz(Y) - These polynomials happen to have zeros at {0, 1, 2, …, 8} - But the product Az(Y)·Bz(Y) is a higher-degree polynomial - It can (and does) have non-zero values between and beyond the integer points

Geometric intuition: - Imagine Az(Y) as a curve passing through points where Az is 0 or 1 - Imagine Bz(Y) as another curve passing through the Bz values - The product of these curves is generally non-zero except at the specific integer points

Accumulation with Equality Polynomials

Assuming for simplicity:

eq_out(cycle_0) = 0.5
eq_out(cycle_1) = 0.3

t1(Y=5) = eq_out(0) * eq_in * product_cycle0 
        + eq_out(1) * eq_in * product_cycle1
        
        = 0.5 * 1.0 * (-85494528)
        + 0.3 * 1.0 * 367080840

Part 4: Understanding the Extended Domain

Why 8 Extended Points?

Group 0 has 9 constraints (indices 0-8), mapping to base window {-4, -3, -2, -1, 0, 1, 2, 3, 4}.

For interpolation to work, we need: - Total of 17 points (symmetric window {-8, …, 8}) - 9 points in base window (all zero) - 8 points in extended domain (non-zero, to be computed)

The 8 extended points: - Negative side: {-8, -7, -6, -5} - Positive side: {5, 6, 7, 8}

Why symmetric? - Optimization: Symmetric structure allows for more efficient computation - The polynomial has certain symmetry properties that can be exploited

What Happens at Each Extended Point?

Each extended point Y requires: 1. Computing Lagrange shift coefficients for that Y 2. For each cycle: - Interpolate Az to Y - Interpolate Bz to Y - Compute product - Weight by eq polynomials - Accumulate

After all cycles processed, we have: - t₁(-8), t₁(-7), t₁(-6), t₁(-5), t₁(5), t₁(6), t₁(7), t₁(8)

Combined with 9 zeros in base window: - t₁(-4)=0, …, t₁(4)=0

This gives 17 evaluations total.

Part 5: Reconstructing the Full Polynomial

From Evaluations to Coefficients

We have 17 evaluations of t₁(Y):

evals = [
    t₁(-8), t₁(-7), t₁(-6), t₁(-5),  # extended negative
    0, 0, 0, 0, 0, 0, 0, 0, 0,        # base window (all zeros)
    t₁(5), t₁(6), t₁(7), t₁(8)       # extended positive
]

Using Lagrange interpolation on these 17 points gives us the polynomial coefficients:

\[t_1(Y) = \sum_{i=0}^{16} a_i Y^i\]

Example: Degree-2 Toy Example

To illustrate, imagine we only had 3 points:

evals = [f(-1), f(0), f(1)] = [2, 0, 4]

Lagrange interpolation gives:

f(Y) = a₀ + a₁Y + a₂Y²

Solving the system:

f(-1) = a₀ - a₁ + a₂ = 2
f(0)  = a₀           = 0
f(1)  = a₀ + a₁ + a₂ = 4

Solution:

a₀ = 0
a₁ = 1
a₂ = 3

So f(Y) = Y + 3Y²

For Our 17 Points

The same principle applies, but with 17 equations and 17 unknowns:

coeffs = lagrange_interpolate_17_points(evals)
# Returns [a₀, a₁, a₂, ..., a₁₆]

This gives us t₁(Y) as an explicit polynomial.

Part 6: The Final Multiplication

Building L(τ_high, Y)

Given challenge τ_high, we evaluate the 9 Lagrange basis polynomials:

L₀(τ_high) = value₀
L₁(τ_high) = value₁
...
L₈(τ_high) = value₈

Then interpolate these 9 values to get polynomial L(Y):

L(Y) = l₀ + l₁Y + l₂Y² + ... + l₈Y⁸

Multiplying L(Y) · t₁(Y)

L(Y) = l₀ + l₁Y + ... + l₈Y⁸        # degree 8
t₁(Y) = a₀ + a₁Y + ... + a₁₆Y¹⁶     # degree 16

s₁(Y) = L(Y) · t₁(Y)                 # degree 8+16 = 24

Convolution:

for i in 0..24:
    s₁[i] = sum(L[j] * t₁[i-j] for j in 0..min(i,8) if i-j <= 16)

Result: 25 coefficients [s₀, s₁, …, s₂₄]

This is the polynomial sent to the verifier!

Summary: The Complete Picture

  1. For each extended point Y (8 total):
    • Compute Lagrange shift coefficients
    • For each cycle:
      • Evaluate Az and Bz at discrete constraint indices
      • Interpolate to Y using coefficients
      • Compute product Az(Y) · Bz(Y)
      • Weight and accumulate
    • Result: t₁(Y) at this extended point
  2. Combine with base window zeros:
    • 9 zeros at {-4, …, 4}
    • 8 computed values at {-8,-7,-6,-5,5,6,7,8}
    • Total: 17 evaluations
  3. Interpolate to get polynomial:
    • t₁(Y) as 17 coefficients (degree-16 polynomial)
  4. Build Lagrange mask:
    • L(τ_high, Y) as 9 coefficients (degree-8 polynomial)
  5. Multiply:
    • s₁(Y) = L(Y) · t₁(Y)
    • Result: 25 coefficients (degree-24 polynomial)
  6. Send to verifier:
    • Verifier evaluates s₁(r₀) at challenge point
    • Sumcheck continues…

The key insight: By exploiting sparsity (Az·Bz = 0 at integer points) and using Lagrange interpolation, we reduce the first round computation from exponential to linear cost!
